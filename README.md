# Много Свай — фронтенд

Откройте эту папку в VS Code и запустите **Open with Live Server** на корневом `index.html`. Сайт откроется по адресу `http://127.0.0.1:5500/`.

- `index.html` — главная страница.
- `montazh/`, `partners/`, `blog/` — внутренние страницы.
- `assets/css/` — стили; `assets/js/` — интерактивность; `assets/images/` — изображения WebP.
- `ref/` — исходные материалы и ТЗ заказчика.
- `site/` — копия, использованная для опубликованного приватного превью. Для Live Server она не нужна.

Заявки не отправляются с сайта. Модальная форма подготавливает письмо в почтовом приложении пользователя; отправку он подтверждает сам. Корзина сохраняется только в браузере.

Страница доставки и самовывоза: `shipment/index.html` (`/shipment/`). Переработанная страница партнёрам: `/partners/`.

Общие модальные формы находятся в `assets/js/lead-form.js`; открываются кнопками с `data-lead`. Для партнёров форма содержит только имя и телефон. Для остальных заявок дополнительно указывается населённый пункт. Серверной отправки и загрузки файлов нет.

На первом экране страницы партнёров используется изображение `assets/images/partner-builder.jpg`, подготовленное из файла `ref/Строитель у каркасного дома на сваях.png`.

Карты складов встроены через виджет Яндекс Карт по координатам. Под каждой картой есть ссылка на полноразмерную карту, если сторонний виджет не загружается в браузере.

Сверка выполненного и оставшихся пунктов ТЗ: `docs/requirements-review.md`. Рабочая версия находится в корне проекта; историческая копия `site/dist` автоматически не обновляется.
